# banking-data-transformation-platform

## Overview

A project designed to explore data engineering, data anlytics, machine learning, cloud computing, DevOps, and application Security through a simulated banking environment.

## Project Goals

- Build a relational database to support a banking system
- Develop an ETL pipeline
- Create a REST API
- Build a web application
- Perform data analytics
- Develop a machine learning model
- Implement security controls
- Containerize the application
- Build a CI/CD pipeline
- Deploy components to AWS
- Implement application monitoring
